# إطلاق عنوان بالنشر قبل السداد

المسار الرسمي: إكمال الحساب ← بطاقة الاشتراك السنوي (180 ريال شامل الضريبة عند عدم وجود خصم عام) ← «انشر صفحتي» ← نشر التصميم والرابط فورًا ← تواصل الفريق لإرسال الفاتورة ورابط الدفع ← تأكيد السداد من الإدارة.

النص قبل النشر: «انشر صفحتك الآن، وبنتواصل معك لإرسال الفاتورة ورابط الدفع.»
النص بعده: «صفحتك منشورة وتقدر تشاركها الآن. بنتواصل معك لإرسال فاتورة الاشتراك ورابط الدفع.»

## ما يحدث في الخادم

`checkout.publish` يقفل حساب العميل وصفحته داخل معاملة واحدة، ويتحقق من توثيق البريد وأنه مسار رسمي، ويمنع تجاوز مساري الجمعية والشريك. يقارن السعر المعروض بالتسعير الحالي، ويرفض سلة سابقة بإضافات/خصم مختلف، وصفحة موقوفة أو عنصر تحرير غير مكتمل. يستخدم `savePageData` نفسه لنشر كامل المسودة، ويثبت الرابط ثم يمسح المسودة المنشورة.

يسجل سلة سنوية عادية بعلامة `manual_published_at`، وحالة `pending_payment`، واشتراكًا بانتظار السداد بلا تاريخ تفعيل أو انتهاء. لا يستدعي تفعيل الاشتراك أو إنشاء دفعة أو إيصال أو احتساب حصة شريك. لا توجد مهلة سداد أو إيقاف آلي لم يوافق عليه المستخدم.

قفل الحساب والطلب السابق يمنعان تكرار إنشاء الطلب أو إعادة نشر المحتوى عند تكرار الضغط أو فقد الرد. بعد النجاح يعاد تحميل شاشة النتيجة من الخادم لتحديث مراجعة الصفحة وحالة الحساب ومنع إعادة إرسال نسخة محرر قديمة.

الروابط العامة تستخدم جدول العناوين المثبتة وحالة الصفحة المنشورة الحالية؛ لا نغير قواعد إيقاف أو حظر الصفحات. يستطيع المستخدم تعديل صفحته بعد النشر بالوظائف الحالية، مع بقاء الاشتراك بانتظار السداد.

## عمل الفريق

1. افتح العملاء ← فلتر «سلة بانتظار الدفع» ← العميل.
2. تظهر السلة وقيمة الاشتراك وبيانات التواصل، وحالة النشر قبل السداد.
3. أضف رابط فاتورة HTTPS ورابط الدفع الذي أنشأته لدى البنك، واحفظهما.
4. يظهر الرابطان في إعدادات العميل وشاشة النتيجة. إرسال رسالة البريد/الجوال يبقى يدويًا؛ حفظ الروابط لا يرسلها تلقائيًا.
5. بعد التحقق الفعلي من السداد، استخدم «تأكيد دفع السلة كاملة» مع مرجع العملية. يستخدم النظام `completeCart` الحالي لتفعيل السنة وتسجيل الدفع وتحويل السلة إلى مدفوعة. تكرار التأكيد لا يمدد الاشتراك مرتين.

روابط الإدارة تقبل HTTPS فقط ولا تقبل بيانات اعتماد مضمنة أو javascript. لا تجمع المنصة بيانات بطاقة. لا تعتبر زيارة رابط الدفع أو قول العميل إنه دفع دليل سداد. لا يوجد خصم/تجديد تلقائي لدفعات الروابط اليدوية.

## تجهيز قاعدة البيانات

خلال هذا العمل طُبق phase34 (إدراج/تحديث السعر السنوي إلى 180) وphase35 (ثلاثة أعمدة للسلة) على قاعدة المشروع المضبوطة، في معاملة واحدة. كان جدول حفظ البداية وعمود إكمال الحساب موجودين عند الفحص الحالي. لم تنشأ حسابات أو صفحات أو مدفوعات حقيقية أثناء هذا التجهيز، ولم تُرسل رسائل.

الكود محلي ولم يُنشر إلى Worker. يجب نشر الكود قبل استخدام المسار على الموقع الحقيقي. بوابة الدفع الآلي ما زالت غير مربوطة، ومسارا الجمعيات والشركاء لم يُفتح لهما نشر قبل السداد بهذه الميزة.

## التحقق

اختبارات وحدة للتراجع عند الفشل وتغير السعر، حفظ كامل التصميم، منع تكرار الطلب، فصل صلاحيات المسارات، حالات النتيجة، أمان روابط الإدارة وتكرار تأكيد السداد.

اختبار تكامل على PostgreSQL محلي مؤقت يستخدم مخطط المشروع وترحيلاته الحقيقية: نشر المسودة، جلبها بمسار الزائر، التحقق من بقاء السلة والاشتراك بانتظار السداد دون سجل دفع، تكرار الطلب، ثم تسوية يدوية عبر completeCart. تُلغى بيانات الاختبار كلها. الاختبار يمنع عنوان قاعدة خارجي ويعطل تحديث الكاش.

رفضت المراجعة التلقائية محاولة اختبار مماثل على القاعدة الخارجية، فلم تُنفذ. استُبدلت بقاعدة محلية معزولة؛ لا يوجد ادعاء باختبار عميل حقيقي أو سداد حقيقي. الفحص البصري التفاعلي ما زال معلقًا بسبب تعذر أداة المتصفح.
