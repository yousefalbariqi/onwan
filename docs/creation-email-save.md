# حفظ بداية الصفحة بالبريد

المسار الرسمي الجديد: اختيار الفئة ← القوالب ← «استخدم هذا التصميم» ← `/signup?step=save` ← رمز التحقق ← حفظ المسودة ← `/signup?step=edit`.

واجهة عربية بحقل بريد واحد، زر متابعة معطّل حتى صحة البريد واجتياز التحقق البشري عند تفعيله، روابط الدخول والشروط والخصوصية، وتوضيح أنها خطوة حفظ دون دفع أو نشر. بعد الإرسال يستخدم نفس النموذج حقل رمز واحد. الخطأ يبقي التصميم والبيانات، وإعادة محاولة الحفظ بعد نجاح التحقق لا تستهلك رمزًا آخر.

## التشغيل

- تطبيق `database/phase32-creation-email-drafts.sql` بعد phase31 **قبل نشر الكود**. ملف الترحيل مُجهز ولم يُطبق خلال هذا العمل. تعتمد استعلامات حماية ملفات المسودات أيضًا على الجدول الجديد.
- إعداد خدمة البريد الحالية: `RESEND_API_KEY` و`EMAIL_FROM` بعنوان إرسال موثّق، وإعداد توقيع الجلسات الحالي. لا تعرض هذه القيم في الواجهة.
- إبقاء إعدادات Turnstile الحالية متطابقة بين الواجهة والـWorker عند تفعيلها، وربط تخزين MEDIA لرفع الصور والوثائق.
- تشغيل المشروع محليًا بالطريقة الحالية `npm run dev:local`؛ لا يتضمن العمل نشرًا أو إرسال بريد تجريبي حقيقي.

## الحفظ والصلاحيات

حساب العميل الحالي يحتاج هاتفًا وكلمة مرور. لذلك لا ننشئ عميلًا ببيانات وهمية ولا نغيّر هذا القيد. البريد المتحقق يحصل على جلسة `creation` مرتبطة بمسودة واحدة في `creation_email_drafts`، ويمكنه قراءة وحفظ مسودته ورفع الملفات عبر آلية التخزين الحالية. جلسة المسودة لا تمنح صلاحية نشر أو دفع أو فتح صفحات العملاء أو الشركاء أو الإدارة.

يرتبط البريد بمسودة بعد استهلاك رمز البريد بنجاح فقط. الإرسال لا يكشف وجود حساب. بعد إثبات ملكية بريد مرتبط بعميل، تظهر روابط الدخول واستعادة الوصول مع البريد معبّأ؛ يبقى التصميم المختار محليًا ولا تُستبدل صفحة الحساب القائمة تلقائيًا.

حفظ التصميم محلي أولًا عبر IndexedDB، ثم رفع الصور/الوثائق المضمنة وحفظ JSON سحابيًا. الجلسة في sessionStorage وتحتوي بيانات الوصول فقط، لا نسخة الصفحة. إعادة التحقق من جهاز بلا مسودة محلية تسترجع أحدث مسودة لذلك البريد. مفتاح محلي لكل بداية يمنع استبدال بداية أخرى للبريد نفسه. الحفظ يستخدم revision ومفتاح عملية لإعادة المحاولة؛ تعارض نسخة أحدث يوقف الاستبدال ويحافظ على الفرع المحلي.

الملفات تستخدم خدمة الوسائط الحالية وروابطها؛ لا يغيّر هذا العمل نموذج إتاحة الملفات ولا يدّعي توفير ملفات خاصة. تخصيص الفيديو والخطوط المتقدم يبقى ضمن القيود الحالية. إكمال الحساب بعد التصميم موثق في `creation-account-completion.md`؛ النشر ما زال يخضع لمسار الحساب والاشتراك ولا يحدث بالبريد وحده.

## التحقق

نجح بناء الإنتاج وفحص Worker. اختبارات مركزة تتحقق من صحة البريد والرمز، عدم الإنشاء قبل إثبات الملكية، فصل صلاحيات الجلسات، حفظ القالب، إعادة المحاولة بعد فشل الحفظ أو التخزين المحلي، منع استبدال نسخة أحدث وإعادة استخدام العملية عند فقد الرد. لم يُختبر إرسال بريد فعلي أو تطبيق الترحيل على قاعدة حقيقية؛ يلزم فحصهما في بيئة اختبار مجهزة. المراجعة البصرية معلقة بسبب تعذر أداة المتصفح، وليست ناجحة ضمنيًا بالبناء.
